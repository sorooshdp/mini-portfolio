# Mini Portfolio

A clean and responsive single-page portfolio website showcasing front-end development skills.

## Features

- **Responsive Design**: Adapts seamlessly to different screen sizes
- **Smooth Navigation**: Fixed navbar with smooth scrolling to sections
- **Interactive Elements**: Hover effects and animations throughout
- **Project Showcase**: Grid layout displaying portfolio projects
- **Contact Form**: Functional form with styled inputs
- **Social Links**: Footer with social media icons (GitHub, Instagram, Twitter, Telegram)

## Technologies

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- Font Awesome icons
- Google Fonts (Nunito, Dancing Script)

## Usage
Simply open `index.html` in a web browser to view the portfolio.
